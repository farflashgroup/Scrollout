# Third-party software

Scrollout bundles the following open-source libraries. Original license files are included in the distribution's `licenses` directory.

- React and React DOM — MIT.
- Lucide icons — ISC; includes icons contributed under the MIT license.
- fflate — MIT.
- pdf-lib — MIT.
- Inter — SIL Open Font License 1.1. The original font license is also in `brand/Inter-LICENSE.txt`.

Build and test dependencies are recorded in `package.json` and `package-lock.json` and retain their respective licenses. The locally authored Scrollout source is private; this project does not assert an open-source license for it.

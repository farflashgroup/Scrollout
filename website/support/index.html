Take a full-page screenshot

  1. Open a normal website in desktop Chrome 120 or newer.
  2. Click Scrollout in the toolbar. Keep the source page active while it scrolls.
  3. The editor opens after capture. Click the icon again or press Escape on the source page to cancel.

Edit and export

Select a tool and drag on the screenshot. Select an annotation to move or resize it. Double-click text to edit it. Crop requires Apply crop or Enter. Use Export for PNG, JPEG, or A4 PDF, or Copy image for a PNG clipboard copy.

Keyboard: V Select, C Crop, D Draw, H Highlight, A Arrow, S Shapes, T Text, R Redact. Ctrl+Z undoes; Ctrl+Shift+Z redoes. Delete removes a selected annotation.

Capture did not finish

Chrome-owned pages, the Chrome Web Store, some viewers, and other protected pages can block capture. Local files require Chrome’s Allow access to file URLs setting. Wait for changing pages to settle and try again. Do not switch tabs, scroll manually, or resize the viewport during capture.

My capture expired

Scrollout is a temporary editor. Closing or leaving the last editor deletes that capture. Browser restarts and extension reloads expire temporary sessions. Download anything you want to keep before closing the editor.

A large image arrived as a ZIP

To stay within browser canvas limits, large PNG and JPEG images are split into numbered parts in one ZIP. The included parts.json describes their positions. PDF uses A4 pages. Oversized clipboard images need to be exported instead.
